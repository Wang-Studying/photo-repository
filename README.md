# 照片仓库（Windows 桌面）

像手机相册一样浏览、分类和整理本地照片：网格、时间线、相册、标签、收藏、搜索、回收站、裁剪（普通照片非破坏式记录，实况裁剪生成可播放的新实况），以及 iPhone / Google / Samsung 动态照片（实况）的悬停播放。默认不改写原件，存储位置由你选择，可放在 U 盘等可移动介质。

## 功能一览

- **导入**：文件 / 文件夹 / 拖放 / **手机有线（数据线）无损传输**；SHA-256 去重；导入前后字节级校验。
- **浏览**：虚拟滚动网格、按天分组、日期前复选框一键选中该日全部内容、缩略图尺寸滑块、照片 / 视频 / 实况筛选。
- **分类**：相册（新建/重命名/删除/加入/移出）、标签、收藏、时间线。
- **实况**：识别 iPhone 配对、Google 内嵌、Samsung 变体；网格悬停静音循环播放，移出即停；保存裁剪后生成新的可播放实况，播放内容与裁剪保留区域一致。
- **查看器**：静态图 / 实况 / 视频均按可视区域自适应显示（无需滚动即可看全）；实况与视频进入即自动播放、点击画面暂停/继续；左右切换、信息面板、原件 SHA-256 校验、在文件夹中显示。
- **编辑**：仅裁剪；自由 / 1:1 / 4:3 / 3:2 / 16:9；保存裁剪一律在当前目录另存为新文件，原图保持不变——普通照片生成新的裁剪图；实况照片生成新的裁剪实况（JPG + 同名 MP4，可直接播放，原图保留）；可导出 PNG 无损副本。
- **删除**：软删除进回收站、还原、彻底删除、清空回收站。
- **存储**：首次启动选择存储根；迁移到新位置（逐文件校验，原库保留）；断连只读降级、重连恢复；重建索引、清理缓存。

## 安装与启动

从 [Releases](https://github.com/Wang-Studying/photo-repository/releases) 下载最新安装包：

- 安装版 `PhotoRepository-Setup-1.0.1-x64.exe`：运行后按向导选择安装目录。
- 便携版 `PhotoRepository-Portable-1.0.1-x64.exe`：直接运行，无需安装。
- 也可从源码运行，见下文「开发与打包」。
- 首次启动会提示选择存储位置。选择空文件夹或已有照片仓库目录均可；也可稍后点击「查找已有照片仓库」。
- 应用未做代码签名，Windows SmartScreen 可能提示；选择「仍要运行」即可。

## 使用说明

### 导入

1. 点击右上角「导入」选择文件，或「导入文件夹」整目录导入，也可把文件/文件夹拖进窗口。
2. 导入按 4 路并发复制，先用系统级复制落盘，再对目标文件计算 SHA-256 去重；相同内容的文件自动跳过。
3. 导入过程中顶部显示百分比进度条与当前文件名，每完成一张照片就实时出现在网格中，不必等全部结束。

### 从手机导入（无损）

在顶栏点「📱 从手机导入」，应用会自动检测已连接的外部设备：

1. 数据线连接手机：iPhone 解锁并点「信任此电脑」；Android 选择「文件传输（MTP）」。
2. 打开弹窗即开始检测：检测中显示「正在检测设备…」，检测到设备显示「已检测到设备，请耐心等待」（随后列出相册内容），未检测到显示「未检测到设备」。
3. 相册内容以卡片网格展示：每张卡片带大幅封面预览（按 4:3 展示可辨识画面，生成一张显示一张），便于按画面挑图，而不是只看文件名；卡片同时标注「照片 / 实况 / 视频」与文件大小，勾选后卡片高亮，再点「导入所选」即可入库。接好手机后点「重新检测」。
4. 封面优先用 Windows Shell 缩略图；设备不支持时自动改为「复制首个文件到本机再生成封面」，生成较慢时状态行会提示「正在生成预览」，全部失败则标注「预览不可用」，不影响导入。
5. 导入时由 Shell 把所选文件直接复制到库内暂存区（`.photo-repo/phone-incoming`，与目标存储同卷），入库时原地改名就位——全程不经过 `%AppData%` 中转，也不产生第二份数据，占用空间约等于文件本身大小；复制全程静默，不弹系统「正在复制…」对话框。复制失败会给出具体原因（手机断开 / 需要解锁允许访问 / 超时 / 文件未找到），可点「重新检测」后重试。

同主名的 iPhone 实况（`HEIC + MOV`）会合并成一个「实况」条目，选中即导入两张；导入自动做 SHA-256 校验，原文件逐字节不变。

### 浏览与筛选

- 左侧「图库 / 收藏 / 回收站」切换视图；下方是相册列表与标签云。
- 每个日期标题前有复选框：点击可一次选中该日期分组内的全部照片 / 视频 / 实况，再次点击整组取消；组内只选中一部分时显示为半选状态。
- 顶部「全部 / 照片 / 视频 / 实况」筛选媒体类型。
- 搜索框支持文件名、标签、相册名。
- 在网格区域按住 `Ctrl` 滚动鼠标滚轮调整缩略图大小（120–320 px）。
- 中键滚动（与浏览器原生一致）：在内容区域**按住中键**上下移动，按偏移方向与距离控制滚动方向与速度；**快速点按中键**进入粘滞滚动模式（原点出现圆形标记），再点任意鼠标键、`Esc` 或滚动滚轮退出。直接滚动滚轮保持平常速度不变。若环境不支持中键事件，等效替代触发方式为「按住 Alt + 左键上下拖动」（占位说明，未实现）。
- 鼠标悬停时瓦片弹性放大；实况/视频按原始比例带声音循环播放，移开即停并恢复原样（约 80 ms 触发）；悬停期间瓦片右上角的圆形按钮可切换静音/取消静音。
- 打开查看器时，实况与视频会自动开始播放；在画面上点击任意位置可暂停 / 继续（图片区域同样生效）。查看器会预加载下一张，左右切换更即时；拖放时显示待导入的项目数量。

### 查看与操作

- 双击瓦片打开查看器；`←` / `→` 切换，`Esc` 关闭，`F` 收藏。
- 静态图、实况、视频打开后都按可视区域等比缩放显示，完整画面一目了然，无需滚动滚轮。
- 实况与视频打开即自动播放：点击画面任意位置暂停，再点继续；空格键等效。切换条目时自动停止并复位播放状态。
- 底部按钮：收藏、标签、相册、裁剪、位置、删除。
- 右上角 `ⓘ` 打开信息面板，可查看尺寸、时间、设备、哈希并执行校验。
- 右键瓦片可收藏、编辑标签（逗号分隔）、加入相册、在文件夹中显示、删除/还原。
- 勾选瓦片左上角圆圈进入多选；`Ctrl+A` 全选，`Delete` 删除/彻底删除，`Esc` 取消选择。
- `Ctrl+O` 打开导入对话框。

### 视频播放（电影式控制）

打开视频后自动开始播放，并按可视区域自适应铺满画面；画面底部出现播放控制条：

- 点击画面任意位置暂停 / 继续，圆形按钮与空格键等效（播放中显示暂停图标，暂停时显示播放图标）。
- 「后退 10s」「前进 10s」：从当前位置后退/前进 10 秒；到片头或片尾时对应按钮自动置灰。
- 进度条可拖动定位，左侧显示当前时间 / 总时长。
- 右下角「1.0x」为倍数播放入口：点击展开 0.25x、0.5x、0.75x、1.0x、1.25x、1.5x、2.0x 七档；当前档位高亮并带勾选标记，按钮回显当前倍数；切换立即生效，并在后续视频中保持。
- 播放时鼠标静止约 2.6 秒控制条自动淡出，移动鼠标即重新出现；暂停时常驻，避免遮挡画面。
- 播放失败（如源编码无法解码）会保留封面并提示，原文件始终不受影响。

### 裁剪

1. 查看器中点击「✂ 裁剪」。
2. 拖动裁剪框或四边/四角手柄，或选择固定比例。
3. 「保存裁剪」——无论哪种类型都**在当前目录另存为新文件，原文件始终不变**：
   - **普通照片**：另存为一张新的裁剪图（与裁剪框同尺寸），文件名形如 `原名-裁剪.jpg`（重名自动追加序号）；原图不被改写，也不在索引中标记裁剪。
   - **实况照片**：在**当前目录**生成一张全新的裁剪实况：裁剪后的 JPG + 同名 MP4，并把裁剪后的动态视频内嵌到 JPG 尾部。新视频为 H.264/AAC + faststart，可在本机直接播放，无需额外转码；原图与原始动态视频保持不变。
   - 在文件管理器等外部环境中悬浮预览该新实况时，播放的是裁剪后的内容（包括从 JPG 内嵌段读取动态画面）。
4. 「导出副本」把当前裁剪结果导出为 PNG（无损）到指定位置。
5. 「重置选区」清空当前裁剪矩形。

> 裁剪为完全非破坏式：不提供「覆盖原图」「恢复原图」「另存新图」入口，因为保存只会在原图之外新增文件，原件在任何情况下都不会被改写。

### 回收站

- 删除默认移入回收站，文件被移动到库内 `Trash/<条目ID>/`。
- 在回收站可「还原」回原路径，或「彻底删除」永久移除。

### 设置与存储

点击左下角「设置」：

- **存储位置**：查看当前库根；「打开目录」在资源管理器中打开；「迁移到新位置」逐文件复制并校验后切换，原库默认保留。
- **索引**：「重建索引」扫描库目录，按哈希合并已有收藏、标签、相册、裁剪信息；「清理缓存」删除缩略图/封面/兼容预览，不影响原件与分类。
- **可移动介质**：库根在 U 盘时，拔出后应用进入只读模式并提示；重新插入后如盘符变化，会按库 ID 自动查找；也可在引导页点击「查找已有照片仓库」。

## 库目录结构

```
{{storage_root}}/
├─ Photos/YYYY/YYYY-MM/     静态原图（裁剪生成的裁剪图/裁剪实况也保存在这里）
├─ Videos/YYYY/YYYY-MM/     独立视频
├─ Live/YYYY/YYYY-MM/       实况关联视频
├─ Derived/Crops/           裁剪导出副本
├─ Trash/<条目ID>/          回收站
└─ .photo-repo/
   ├─ library.json          索引（可重建）
   └─ cache/                缩略图、封面、全尺寸视图、兼容预览（可清理）
```

## 像素保真说明

- 导入、迁移、裁剪导出均保持原始像素；任何操作都不会改写原件。保存裁剪只会在当前目录新增文件（新裁剪图或新裁剪实况），原图与原始动态视频保持不变。
- 网格缩略图、视频封面、非 JPEG 的全尺寸视图、HEVC 兼容预览都属于**显示层**，写入 `.photo-repo/cache`，可随时删除重建，不参与导出。
- 查看器统一按可视区域自适应显示：静态图、实况、视频都等比缩放，无需滚动即可看全。
- HEVC 视频若浏览器无法直接播放，会生成 H.264 兼容预览用于显示，原视频文件不变。

## 支持格式

| 类型 | 格式 | 说明 |
| --- | --- | --- |
| 图片 | JPG / PNG / WebP / GIF / BMP / TIFF / AVIF / HEIC / HEIF | HEIC 使用内置 WASM 解码，不依赖系统 HEIF 扩展 |
| 视频 | MP4 / MOV / M4V / WebM / MKV / AVI | HEVC 自动生成显示层兼容预览 |
| RAW | DNG / CR2 / NEF / ARW / RAF / ORF / RW2 / SRW | 可入库保存，界面标记「格式待支持」 |
| 实况 | iPhone 配对、Google Motion Photo、Samsung 变体 | 识别失败时保留静态图并标记「实况 · 待支持」 |

## 开发与打包

```bash
npm install
npm start        # 开发运行
npm run build    # 生成 NSIS 安装包 + 便携版到 dist/
npm run pack     # 仅生成免安装目录 dist/win-unpacked/
```

- 依赖：Electron 32、sharp、heic-decode、exifr、静态 ffmpeg（`@ffmpeg-installer/ffmpeg`）。
- 打包时若访问 GitHub 受限，可设置镜像：
  ```powershell
  $env:ELECTRON_BUILDER_BINARIES_MIRROR='https://npmmirror.com/mirrors/electron-builder-binaries/'
  npm run build
  ```
- 未配置代码签名证书，安装包与可执行文件未签名；如需签名，在 electron-builder 中配置 `certificateFile` / `certificatePassword`。

## 数据与隐私

- 全部数据仅保存在你选择的存储根，以及安装目录下的配置/缓存目录 `photo-repo-data`（便携版为 exe 同级的 `photo-repo-data`），不写 `%APPDATA%\照片仓库`，不联网、不上传。
- 旧版本写在 `%APPDATA%\照片仓库` 的配置会在首次启动新版本时自动迁到 `photo-repo-data`，迁移成功后删除旧目录；照片库不在搬迁范围内。
- 卸载应用不会删除照片库；如需清空，请在资源管理器中自行删除库根目录。
- 迁移失败不会修改原库；目标副本会被清理。
