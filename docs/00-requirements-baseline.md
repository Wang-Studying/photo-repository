# 照片仓库 · 需求基线（阶段 0）

版本：1.0.0　冻结日期：2026-10-25

## 1. 产品定位

Windows PC 端单机照片仓库。交互与能力对齐手机相册：网格浏览、按时间线聚合、相册与标签、收藏、搜索、回收站、非破坏裁剪、动态照片（实况）悬停播放。所有原文件按字节原样保存，存储根由用户自选，可指向 U 盘等可移动介质。

## 2. 已冻结结论

| 项目 | 结论 |
| --- | --- |
| 技术栈 | Electron 32 + 原生 JS（无前端框架） |
| 目标平台 | Windows 10/11 x64；不含移动端 App |
| 使用模式 | 单机单用户；本期不做账号、云同步、多人协作 |
| 分类维度 | 相册 + 标签 + 时间线 + 收藏 + 媒体类型（照片 / 视频 / 实况）；人脸识别延后 |
| 实况格式 | 全量识别：iPhone 同目录同名 JPG/HEIC + MOV 配对；Google Motion Photo 单文件内嵌 MP4；Samsung 尾部追加 MP4 变体 |
| 识别失败策略 | 原文件照常入库，标记「静态 + 待支持」，不丢数据 |
| 默认存储位置 | 首次启动弹窗选择，不预设目录；位置可迁移 |
| 裁剪语义 | 完全非破坏式另存为新文件：普通照片保存裁剪时在当前目录生成一张新的裁剪图，原文件永不改写、索引中也不再标记裁剪；实况照片保存裁剪时在当前目录生成新的裁剪实况（JPG + 同名 MP4，可直接播放），原图保留；可导出 PNG 无损副本 |
| 删除语义 | 软删除进回收站，可还原；回收站内可彻底删除 |
| 像素保真口径 | 导入、存储、导出链路零有损；显示链路允许缩放（缩略图/查看器适配），但不得回写原文件 |
| 变量占位符 | `{{storage_root}}`、`{{location_theme}}`、`{{title_text}}` 保留原样，由后续配置替换 |

## 3. 范围

### 范围内

- 导入：文件、文件夹、拖放；手机有线（数据线连接，应用内直接勾选相册文件导入）无损传输；去重（SHA-256）；导入进度。
- 浏览：虚拟滚动网格、按天分组、缩放瓦片、按媒体类型筛选、搜索（文件名 / 标签 / 相册名）。
- 分类：相册增删改、加入/移出相册、标签、收藏、时间线。
- 实况：识别、关联件落盘、网格悬停静音循环播放、查看器中进入即自动播放/点击暂停。
- 查看器：按可视区域自适应（静态图 / 实况 / 视频）、进入即自动播放、点击画面暂停/继续、上一张/下一张、信息面板、字节哈希校验。
- 编辑：仅裁剪；自由/1:1/4:3/3:2/16:9 比例；保存裁剪一律另存为新文件（普通照片生成新裁剪图，实况生成新实况），原图与原始动态视频始终不变；导出裁剪副本。
- 删除：单条/批量软删除、还原、彻底删除、清空回收站。
- 存储：库根目录选择、迁移（逐文件 SHA-256 校验）、断连只读降级、重连恢复、索引重建、缓存清理。
- 打包：NSIS 安装包 + 便携版。

### 非范围

- 移动端 App、云同步、账号体系、多用户权限。
- 除裁剪外的任何像素编辑（滤镜、旋转写入、调色、磨皮等）。
- 人脸识别、场景识别、自动相册。
- RAW 的像素显示（可入库保存，界面标记「格式待支持」）。
- 视频剪辑、转码导出（仅为兼容播放生成显示层预览）。
- 系统级文件实时监听（新增文件需通过导入或重建索引进入库）。

## 4. 术语表

| 术语 | 含义 |
| --- | --- |
| 存储根 `{{storage_root}}` | 用户选定的库根目录，库内全部文件都在其下 |
| 原件 | 导入时按字节复制、经二次哈希校验的文件，之后永不被改写 |
| 关联件 | 实况照片对应的短视频/动态段，与静态主图建立关联 |
| 派生件 | 由原件生成的显示或导出文件（缩略图、全尺寸视图、兼容预览、裁剪导出），可随时重建 |
| 非破坏裁剪 | 保存裁剪时在当前目录另存为新文件，原文件永不被改写：普通照片生成新的裁剪图，实况裁剪生成新的裁剪实况 |
| 自适应显示 | 查看器中静态图 / 实况 / 视频一律按可视区域等比缩放显示，无需滚动即可看全 |
| 显示层缩放 | 仅为屏幕显示生成较小图像，不回写原件 |
| 兼容预览 | HEVC 等浏览器不可直接播放的视频，生成仅供显示的 H.264 预览 |

## 5. 验收口径

1. **字节保真**：导入前后原件 SHA-256 完全一致；迁移前后同样一致。
2. **实况关联**：三类样本（iPhone 配对 / Google 内嵌 / Samsung 变体）均能识别并抽取可播放动态件；失败时降级为静态且标记待支持。
3. **悬停播放**：指针进入实况/视频瓦片约 120 ms 后开始静音循环播放，移出即停；多次进出不残留。
4. **裁剪**：保存裁剪后原文件哈希不变，索引中不标记裁剪；普通照片在当前目录生成新的裁剪图（尺寸与裁剪矩形一致），实况裁剪在当前目录生成新的可播放实况（JPG + 同名 MP4）；导出副本为 PNG 无损且尺寸与裁剪矩形一致。
5. **查看器**：静态图 / 实况 / 视频打开后均按可视区域自适应显示（无需滚动即可看全）；实况与视频进入即自动播放，点击画面可暂停/继续。
6. **存储迁移**：迁移后新库可正常打开，条目数、哈希、分类、裁剪、实况关联全部保持；原库保留。
7. **断连降级**：介质不可用时进入只读模式并提示，不写入、不崩溃；恢复后写入功能自动恢复。
8. **打包可用**：安装包与便携版均可在 Windows 10/11 x64 启动，缩略图与实况兼容预览可在打包环境内生成。

## 6. 开放问题与默认值

| 问题 | 处理 |
| --- | --- |
| 真实机型 HEIC 实况样本未覆盖 | 按「原样保存 + 标记待支持」推进；解码使用内置 WASM，不依赖系统 HEIF 扩展 |
| 实况格式厂商差异 | 采用规则识别 + 尾部 `ftyp` 启发式；无法识别时不丢原件 |
| 极端大库性能基线缺失 | 虚拟滚动 + 按需加载；以 2 万文件导入上限作为单次保护阈值 |
| 裁剪是否需保留多版本 | 每次保存裁剪都会生成一个独立的新文件（重名自动追加序号），原件始终保留 |
| 多显示器 / 高 DPI | 使用系统缩放；窗口尺寸记忆；不单独做多屏适配 |

## 7. 风险与回退

| 风险 | 回退 |
| --- | --- |
| 实况识别失败 | 原件照常入库并标记待支持，后续可重建索引重新识别 |
| 保真与性能冲突 | 只做显示层缩放；原文件零改写；缩略图与预览可清理重建 |
| 可移动介质断连 | 3 秒轮询检测，只读降级；重连后恢复写入；按 libraryId 跨盘符查找库 |
| 迁移中断 | 迁移先写目标副本并逐文件校验，失败清理目标副本，原库不动 |
| 裁剪语义争议 | 一律非破坏式另存为新文件：普通照片生成新裁剪图，实况生成新实况，原件永不改写；提供「导出副本」 |
